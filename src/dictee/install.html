Installer « Dictée FR »

Sur iPhone / iPad — rien à installer

Ouvre l'appli web dans Safari, puis Partager → « Sur l'écran d'accueil ». Elle s'ouvre ensuite comme une vraie appli, hors ligne.

Sur Android — installer l'appli

⬇️ Télécharger dictee-fr.apk

Android 8.0 ou plus récent · ~26 Mo

  1. Sur le téléphone, appuie sur le bouton de téléchargement ci-dessus.
  2. Ouvre le fichier dictee-fr.apk (dans les notifications ou l'appli « Fichiers »).
  3. Android affiche « Pour votre sécurité… ». Appuie sur Paramètres, active « Autoriser depuis cette source », reviens en arrière, puis Installer.
  4. Si un avertissement « application non vérifiée » apparaît (Play Protect), choisis « Installer quand même » — c'est normal pour une appli qui n'est pas sur le Play Store.
  5. Ouvre Dictée FR. Au premier usage de l'appareil photo, autorise l'accès.
L'appli web et l'appli Android sont identiques. Sur Android, l'appli te laisse aussi scanner une liste de mots par photo (reconnaissance hors ligne) ; la version web le fait aussi mais plus lentement.

Partager la liste entre appareils

Dans « Gérer les mots », un code famille permet d'avoir la même liste (et les « Mots à revoir ») sur plusieurs téléphones ou tablettes.

  1. Sur le premier appareil : 🎲 Générer, puis 📤 Envoyer (ou 📋 Copier) pour transmettre le code à l'autre appareil.
  2. Sur l'autre appareil : saisis le même code et appuie sur 🔄 Synchroniser. Les deux listes fusionnent (rien n'est perdu).
  3. Ensuite, appuie sur Synchroniser sur l'un ou l'autre appareil chaque fois que tu changes la liste.

Le code ressemble à coq-bleu-h7k2m9 : deux mots suivis de 6 caractères au hasard. Toute personne qui connaît le code peut voir et modifier cette liste — garde-le en famille.
