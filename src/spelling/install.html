Install “Spelling EN”

On iPhone / iPad — nothing to install

Open the web app in Safari, then Share → “Add to Home Screen”. After that it opens like a real app, and works offline.

On Android — install the app

⬇️ Download spelling-en.apk

Android 8.0 or newer · ~26 MB

  1. On the phone, tap the download button above.
  2. Open the file spelling-en.apk (from the notifications or the “Files” app).
  3. Android says “For your security…”. Tap Settings, turn on “Allow from this source”, go back, then tap Install.
  4. If a Play Protect “unverified app” warning appears, choose “Install anyway” — that's normal for an app that isn't from the Play Store.
  5. Open Spelling EN. The first time you use the camera, allow access.
The web app and the Android app are the same. On Android, scanning a word list from a photo happens on the phone, offline; the web version can scan too, but more slowly.

Share the list between devices

In “Manage Words”, a family code keeps the same list (and the “Words to review”) on several phones or tablets.

  1. On the first device: 🎲 Generate, then 📤 Send (or 📋 Copy) to pass the code to the other device.
  2. On the other device: enter the same code and tap 🔄 Sync. The two lists merge (nothing is lost).
  3. After that, the lists sync by themselves whenever the app opens, or pull down to sync.

The code looks like owl-blue-h7k2m9: two words followed by 6 random characters. Anyone who knows the code can see and change that list — keep it in the family. English and French lists are kept apart, even if you use the same code in Dictée FR.
